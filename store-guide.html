🤖 Path 1: Google Play Store R425 — Once

1
Pay the developer fee Android

Go to play.google.com/console → Create account → Pay R425 once (lifetime). No annual renewal needed. Approval takes a few minutes.

2
Generate PNG icons Both

Open icon-generator.html in your browser → download the 192×192, 512×512, and 1024×1024 PNGs. Drop them into TVTime/icons/.

3
Make your PWA publicly accessible Android

PWABuilder needs a public URL. Two options:

Option A (easiest): Install ngrok → ngrok http 8080 → copy the https URL

Option B (permanent): Push your code to GitHub → enable GitHub Pages → use that URL

4
Generate Android App Bundle Android

Go to pwabuilder.com → paste your public URL → click "Package for Stores" → Android → download the .aab file. PWABuilder handles Bubblewrap/TWA automatically — no Java or Android SDK needed on your machine.

5
Upload to Play Console Android

In Google Play Console → Create app → Set up store listing (app name: ShowTracker, description, screenshots) → Upload your .aab → Set up App signing (Google handles it) → Submit for review. Takes 2–4 hours for first review.

📱 Path 2: Huawei AppGallery R0 — FREE

1
Register as a Huawei Developer — FREE Huawei

Go to developer.huawei.com → Register → Complete Real-Name Identity Verification (submit your ID/passport, takes 1–3 days). Cost: R0. No annual fees, no listing fees. This is the cheapest store to publish on.

2
Use the same Android package from PWABuilder Huawei

Huawei AppGallery accepts standard Android .aab and .apk files natively. The exact same TWA package generated by PWABuilder.com for Google Play works perfectly on AppGallery. No changes needed — ShowTracker doesn't rely on Google Play Services (GMS), so it runs great on Huawei devices.

3
Set up digital asset links (for full-screen TWA) Both

To hide the browser URL bar in your TWA wrapper, you need to host a file called .well-known/assetlinks.json on your domain containing your signing certificate fingerprint. This applies to both Google Play and AppGallery. PWABuilder provides this file in its output.

4
Upload to AppGallery Connect Huawei

Go to AppGallery Connect (developer.huawei.com/consumer/cn/console) → Create app → Set up store listing → Upload your .aab → Submit for review. Review usually takes 1–3 days for the first submission.

5
Optional: Add HMS Push Kit for notifications Huawei

If you want push notifications on Huawei devices (since they don't have Google's FCM), integrate Huawei Push Kit via HMS Core. This requires a few lines of native code in your TWA project. PWABuilder's output includes a config file where you can add HMS dependencies. The Push Kit is free with monthly quotas.

🍎 Path 3: Apple App Store R1,700/year

1
Pay the developer fee iOS

Go to developer.apple.com/programs → Enroll → Pay R1,700 per year. This must be renewed annually to keep your app on the store.

2
Get a Mac (or rent one in the cloud) iOS

You need Xcode to build the iOS app. Options:

Own a Mac? Great — install Xcode from the App Store.

No Mac? Use MacStadium (R200–400/mo) or GitHub Actions (free with a Mac runner — I can set this up for you).

3
Install & set up Capacitor iOS

On your Mac (or CI):

npm install @capacitor/core @capacitor/cli
npx cap init ShowTracker com.yourname.showtracker
npx cap add ios
npx cap copy
npx cap open ios

This generates an Xcode project that loads ShowTracker inside a WKWebView.

4
Add push notifications (to pass Apple review) iOS

Apple's Guideline 4.2 requires more than just a website in a WebView. The easiest native feature to add:

npm install @capacitor/push-notifications

This lets you send notifications when newly aired episodes drop. Pair it with @capacitor/share for native sharing and you'll comfortably pass review.

5
Build & submit iOS

In Xcode → Select Any iOS Device → Product → Archive → Upload to App Store Connect → Fill in App Store metadata → Submit for review (takes 1–2 days).
